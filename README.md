## 快速开始

### 1. 配置 API Key

创建 `.env` 文件：
```
QWEN_API_KEY=sk-your-api-key-here
```

### 2. 数据预处理

```bash
python scripts/prepare_call_data.py
```

### 3. 构建索引

```bash
python scripts/build_indices.py
```

### 4. 交互查询

> **注意**: 首次运行需要下载 BGE Embedding 模型（约 1GB），请耐心等待。

```bash
# 交互模式
python scripts/query.py

# 单次查询
python scripts/query.py "外卖到了"
python scripts/query.py "诈骗电话怎么处理"
```

## 系统架构

### Hybrid RAG 流程

```
用户查询 → LLM路由决策
              │
    ┌─────────┼─────────┐
    ↓         ↓         ↓
Vector   Graph    Hybrid
检索     检索     检索
    │         │         │
    └─────────┼─────────┘
              ↓
         RRF 融合排序
              ↓
         Rerank 重排
              ↓
         LLM 生成回复
```

### 检索模式

| 模式 | 触发条件 | 说明 |
|------|----------|------|
| `vector` | 通用语义查询 | 基于向量的语义相似度检索 |
| `graph` | 图谱关键词检测 | 诈骗电话、领导来电等关键词触发 |
| `hybrid` | LLM 决策 | 同时使用向量和图谱检索，RRF 融合 |

## 电话分类及处理规则

系统基于 RAG 向量检索自动识别来电类型，并匹配对应的处理规则。

### 处理动作说明

| 处理动作 | 说明 |
|---------|------|
| **拦截** | 直接挂断电话，并推送提醒短信给机主 |
| **转接** | 记录信息并通过短信通知机主 |
| **优先处理** | 优先记录并立即通知机主 |
| **记录** | 询问是否紧急，记录留言后通知机主 |
| **询问** | 询问来电事由并根据情况处理 |

### 分类处理规则

| 分类 | 处理动作 | 处理规则 |
|------|---------|---------|
| 外卖配送 | 转接 | 机主当前正在上课，请你告知配送员放在东门传达室，提取配送信息发短信通知机主。 |
| 快递取件 | 转接 | 机主当前正在上课，请你告知配送员放在东门传达室或快递柜，提取配送信息发短信通知机主。 |
| 推销电话 | 拦截 | 直接挂断，给机主推送推销来电提醒短信。 |
| 诈骗电话 | 拦截 | 直接拦截挂断，给机主推送风险提醒短信，告知识别到诈骗来电。 |
| 诈骗风险 | 拦截 | 直接拦截挂断，给机主推送风险提醒短信，告知识别到诈骗来电。 |
| 熟人问候 | 记录 | 告知对方机主正在上课，询问是否有急事，不紧急请晚点联系，紧急则记录消息通知机主。 |
| 家人电话 | 询问 | 告知对方机主正在上课，询问是否紧急，不紧急请晚点联系，紧急则记录消息通知机主。 |
| 领导来电 | 优先处理 | 告知对方机主正在上课，询问是否有急事，记录留言后发短信通知机主下课回电。 |
| 同事协作 | 记录 | 告知对方机主正在上课，询问是否紧急，不紧急请留言，紧急则记录消息通知机主。 |
| 客户来电 | 记录 | 告知对方机主正在上课，询问是否有紧急事项，记录留言后发短信通知机主。 |
| 打车到达 | 转接 | 机主正在上课，请告知对方稍等或让其自行等待，记录短信通知机主。 |
| 银行电话 | 记录 | 告知对方机主正在上课，询问是否有紧急事项，记录留言后发短信通知机主回电。 |
| 游戏周年庆 | 拦截 | 直接挂断，标记为营销来电。 |
| 面试通知 | 优先处理 | 告知对方机主正在上课，询问面试时间和联系方式，记录后发短信通知机主。 |
| 其他 | 询问 | 告知对方机主正在上课，询问来电事由并记录。 |
